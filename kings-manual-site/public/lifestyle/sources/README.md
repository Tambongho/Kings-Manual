# Lifestyle source photography

The edited lifestyle images in the parent directory were created from these free-use source photographs:

- `pexels-reading-man.jpg` — “A Man Sitting on a Sofa Reading a Book” by SHVETS production on Pexels: https://www.pexels.com/photo/a-man-sitting-on-a-sofa-reading-a-book-8933542/
